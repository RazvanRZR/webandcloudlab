# Dinamo București — Season showcase

A responsive, buildless HTML/CSS/JavaScript fan website for the 2026/27 season.

Open `index.html` directly in your browser or run `python -m http.server 8080` from this folder and visit `http://localhost:8080`.

Includes match venue filters, upcoming/results views, a full league table, player profile dialogs, and mobile navigation. Images and fonts are stored locally. No dependencies or build step.

Data is a fixed snapshot from 13 October 2026, sourced from [LPF standings](https://lpf.ro/liga-1), [results](https://lpf.ro/cluburi/dinamo-bucuresti/14/rezultate), [fixtures](https://lpf.ro/cluburi/dinamo-bucuresti/14/calendar), and [SuperLiga squad profiles](https://www.superliga.ro/cluburi/dinamo-bucuresti). Update arrays in `script.js` and the overview/date labels in `index.html` when refreshing the snapshot. Fixture dates and times may change.

Club crest: SuperLiga. Player photographs: Dinamo's official website. Historical supporter photograph: Sport.ro, December 2024; used as atmosphere imagery, not a 2026/27 match photo. Fonts: Barlow Condensed and DM Sans via Google Fonts. This is an independent fan showcase; club and photo rights remain with their respective owners.
